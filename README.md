# Projects

A home for personal projects and build ideas. Each project has its own folder and README describing its purpose, stack, and setup.

| Project | Purpose | Status |
| --- | --- | --- |
| [PMO dashboard](ford-pmo-dashboard/) | A from-scratch portfolio dashboard using fictional project information | Planning |
| [Rating tracker](rating-tracker/) | A personal tracker for items and their ratings | Planning |

## Add a project

Create a folder with a short, lowercase, hyphenated name. Add a README with the purpose, tech stack, status, and exact run instructions once code exists.

## Public content

Publish only original code, public information, and synthetic sample data. Never commit employer code, internal details, credentials, or private data. The PMO dashboard folder is reserved for a sanitized write-up or an independent rebuild.
